# Birthday-Wish
A website that wishes happy birthday to my friends. Only Compatible with computers and tablets, NOT phones
## Tools Used
* Canva - For the Website Background Image
* Google Gemini - For guidance in terms of what CSS attribute to use or any general questions
* Github Copilot - Inline suggestions and minimal use for bug fix
* VS Code - IDE
## AI Declaration
Used Google Gemini to explain me some concepts or share some CSS attributes that I needed for my website. Sometimes used Github Inline Suggestion. Used Github Copilot once or twice for bug fixes
